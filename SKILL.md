# Agent Cognitive Upgrade

## Overview

Check framing, expand breadth before depth, and verify solutions. Improve the
method when evidence warrants it; do not turn every task into an audit.

## Entry Gate

Read [entry-gate.md](references/entry-gate.md) first.

- Follow its `no escalation`, `Standard`, or `Deep` route.
- An explicit invocation of this skill is at least `Standard`.

## Deep Is A Blocking Gate

Stop before Deep for the model-upgrade choice and capability disclosure in
[entry-gate.md](references/entry-gate.md). Full analysis is a trigger, not a waiver;
apply that reference's current-task preauthorization rules. Never self-certify
sufficiency, analyze before confirmation, or repeat an accepted gate.

## Analysis

After the gate:

1. Read [analysis-workflow.md](references/analysis-workflow.md) for framing,
   cause breadth, discriminating evidence, and solution design.
2. Before concluding, read
   [verification-and-coverage.md](references/verification-and-coverage.md).

Only when a reusable reasoning/process failure is identified or a rule change
is proposed, read [improvement.md](references/improvement.md). It is not a
mandatory end-of-task reflection and does not authorize persistent changes.

Optional: [reasoning-patterns.md](references/reasoning-patterns.md) for quick
patterns; [portable-global-gate.md](references/portable-global-gate.md) only for
installing a generic pre-skill trigger.

## Non-Negotiables

- Preserve user hypotheses and distinct alternatives; label provenance precisely.
- Fix the evidenced causal link, not merely an adjacent symptom.
- Independent agreement, 5 Why, checklists, and confidence labels are not proof.
- Claim independent review only when it occurred; expose material unknowns.
- Retain all defense aspects and route failure to the earliest invalid stage.
