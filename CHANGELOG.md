# Changelog

## v2.1.0 - 2026-10-03

- Check expected/observed behavior, evidence source, and success criteria before
  diagnosing. Preserve cause-family floors and require discriminating evidence
  for convergence; separate testing priority from causal credibility.
- Preserve blocking model-upgrade confirmation; consolidate its detailed rules
  in the entry reference instead of duplicating them in the main skill.
- Strengthen independent test oracles, scenario/version evidence boundaries,
  solution tradeoffs, and correction-versus-causation claims.
- Add conditional improvement and narrow-scope rule-promotion review with
  original/new/ordinary-case validation and withdrawal criteria.
- Preserve all defense-coverage aspects while allowing compact presentation.

## v2.0.0 - 2026-07-30

- Replaced the old Light/Standard/Deep asset split with a fast entry gate and
  Standard/Deep analysis modes.
- Added blocking confirmation before Deep analysis.
- Added cause-space breadth, blind independent generation, adversarial review,
  provenance controls, coverage analysis, residual-risk decisions, and
  stop/continue rules.
- Added portable metadata and an optional generic global trigger.
- Retired `assets/mode-gate.md` and `assets/output-contract.md`.

## v0.6 - 2026-06-04

- Preserved user-provided causal chains as hypotheses.
- Added checks that proposed solutions cover the actual failure chain rather
  than only adjacent symptoms.
