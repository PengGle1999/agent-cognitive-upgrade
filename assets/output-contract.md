# Output Contract

1. Problem definition
2. Trigger
3. Mode routing result
4. Analysis depth note
5. Evidence
6. Inference
7. Unverified hypotheses
8. Most credible root cause tied back to the evidence
9. Rejected false causes
10. Candidate solutions
11. Recommended solution
12. Coverage map
13. Forward verification
14. Reverse verification
15. Truth confidence
16. Solution confidence
17. Coverage confidence
18. Verification confidence
19. Escalation decision
20. Learning promotion decision

## Entry Gate Rule
- `Trigger` must name the activation signal or signals that caused this skill to be used
- `Mode routing result` must state `Light`, `Standard`, or `Deep` and must reflect the mode precedence rules

## Candidate Solution Rule
- Provide at least 2 candidate solutions
- If only 1 viable option remains, state that only 1 viable option remains and why the alternatives were eliminated
